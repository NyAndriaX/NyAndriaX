# Technology Logos

This directory contains logo images for technologies used in the portfolio.

## Required Logos

Place the following logo files in this directory:

- `symfony.svg` - Symfony logo
- `react.svg` - React logo
- `nextjs.svg` - Next.js logo
- `react-native.svg` - React Native logo
- `javascript.svg` - JavaScript logo
- `typescript.svg` - TypeScript logo
- `python.svg` - Python logo
- `playwright.svg` - Playwright logo
- `flask.svg` - Flask logo
- `tailwindcss.svg` - Tailwind CSS logo
- `antd.svg` - Ant Design logo
- `primereact.svg` - Prime React logo
- `wordpress.svg` - WordPress logo
- `mui.svg` - Material-UI logo
- `docker.svg` - Docker logo

## Logo Specifications

- **Format**: SVG (preferred) or PNG
- **Size**: Recommended 120x40px or similar aspect ratio
- **Style**: White/light colored logos work best on dark background
- **Background**: Transparent

## Fallback Behavior

If logos are not found, the components will display the technology name as text fallback.

## Adding New Technology Logos

1. Add the logo file to this directory
2. Update `app/lib/data/technologies.ts` with the new technology entry
3. Ensure the logo is optimized for web use

## Note

You can find official logos for most technologies on their official websites or on:
- https://github.com/simple-icons/simple-icons (for SVG logos)
- https://www.vectorlogo.zone/ (for technology logos)
